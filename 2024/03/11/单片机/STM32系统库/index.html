引脚定义

GPIO 输入与输出

STM32 GPIO（General Purpose Input/Output，通用输入输出）是 STM32 微控制器中用于与外部设备进行数字信号交互的重要外设模块。

只要可以用高低电平来控制的地方，都可以用 GPIO 来完成。如果控制的是功率较大的设备，需要加入驱动电路。

  • 引脚电平：0V~3.3V，部分引脚可容忍 5V 输入（标有 FT）。

  • 命名方式：GPIOA、GPIOB…等，每组端口最多拥有 Pin0、Pin1…Pin15 共16 个引脚，每个 GPIO 引脚都可以单独配置。

GPIO 结构

所有的 GPIO 都挂载在 APB2 总线上与 CPU 连接。

整体结构可以分为寄存器来驱动器两部分，CPU 通过 APB2 总线对相关寄存器进行读写来完成输出电平和输入电平的功能，而驱动器负责增大驱动能力。

该图展示了 GPIO 端口位的内部电路和功能模块，左半部分为寄存器模块，右半部分为驱动器模块。上半部分为输入路径，下半部分为输出路径。

输入路径： 将外部信号转换为内部数字信号的电路部分。其核心目标是将外部电平（高/低）转换为芯片内部可识别的逻辑值，并存储到输入数据寄存器中。

  • IO 引脚处连接有两个保护二极管，分别连接到 VDD（电源）和 VSS（地），这些二极管在输入电压超出电源范围（0V~3.3V）时导通，用于保护内部电路。
  • 输入驱动器：输入信号经过输入驱动器放大和缓冲，确保信号质量。
  • 输入路径上的 2 个开关控制引脚连接上拉或下拉电阻，其主要作用是给输入提供一个确认的默认电平，防止输入引脚因“悬空”状态导致的电平不确定。
    • 两个开关断开 → 浮空输入。此时不提供默认电平，易受干扰，通常在外部已有上下拉电路时使用。
    • 闭合上拉开关 → 上拉输入。默认电平为高电平。
    • 闭合下拉开关 → 下拉输入。默认电平为低电平。
  • TTL 施密特触发器：用于对输入电压进行整形，将输入信号转换为标准逻辑电平，避免因输入信号波动造成输出抖动现象。
  • 输入数据寄存器：经过整形后，输入信号就可以写入输入数据寄存器 IDR，CPU 可以通过读取寄存器获取该引脚的实时电平状态。
  • 除了直接写入 IDR，输入信号还可以绕过 CPU，直接输入到片上外设，此时分为：
    • 模拟输入：连接到模拟外设，最常见的是连接到模数转换器 ADC，用于采集连续变化的电压信号，此时引脚不再作为数字输入使用。
    • 复用功能输入：连接到数字外设，最常见的是连接到 USART、SPI、I²C 等，让外设自动解析输入信号，此时必须启用该引脚的复用功能（AF）。

输出路径： 将内部信号（来自 CPU 或外设）转换为外部电平的电路部分。其核心目标是通过控制 P-MOS 和 N-MOS 晶体管，实现推挽输出或开漏输出，并驱动外部负载。

  • 输出数据寄存器 ODR：CPU 可以通过写入该寄存器来控制引脚的输出状态，一个 ODR 同时控制 16 个 GPIO 端口。
    • 位设置和清除寄存器（Bit Set/Reset Register）：BSRR 用于单独设置或清楚 ODR 寄存器中的位，而不影响其他位。而且这个写入是原子操作，因此可防止中断干扰。
  • 输出控制模块：根据输出数据寄存器中的值，生成控制信号，驱动 P-MOS 和 N-MOS 晶体管，从而控制 IO 口接到 VDD 还是 VSS。共有 3 种模式：
    • 推挽输出：P-MOS 和 N-MOS 同时工作。ODR 值为 1 时 VDD 导通，输出高电平；ODR 值为 0 时 VSS 导通，输出低电平。可以主动输出高电平或低电平，驱动能力强。
    • 开漏输出：P-MOS 无效，只有 N-MOS 在工作。ODR 值为 1 时无效，VDD 仍断开，端口处于高阻态；ODR 值为 0 时正常输出低电平。常用于 I²C 总线。
    • 输出关闭：P-MOS 和 N-MOS 均无效，IO 口处于输入模式。
  • 复用功能输出：输出由片上外设（如 USART、SPI、TIM 等）直接控制，而非 CPU，适用于串行通信、定时器输出等场景。

GPIO 的工作模式

STM32 的每个 GPIO 引脚可通过寄存器配置为以下 8 种工作模式（4 种输入+4 种输出）。

输入模式下可读取端口的高低电平或电压，用于读取按键输入、外接模块电平信号输入、ADC 电压采集、模拟通信协议接收数据等。

输出模式下可控制端口输出高低电平，用以驱动 LED、控制蜂鸣器、模拟通信协议输出时序等。

模式名称 性质 特征

上拉输入 数字输入 可读取引脚电平，内部连接上拉电阻，悬空时默认高电平
下拉输入 数字输入 可读取引脚电平，内部连接下拉电阻，悬空时默认低电平

按键控制 LED

  • 按键接线图的 4 种不同接法

    1、2 属于下接按键的方式，3、4 属于上接按键的方式。1，2 按下时引脚是低电平，松手是高电平；3，4 按下时引脚是高电平，松手是低电平。一般习惯性地采用 1、2 两种接法。

    1. 按键按下，PA0 被下拉到 GND，此时 PA0 口的电压就是低电平；当按键松手时，PA0 被悬空，电压不确定。所以在接法 1 的情况下，要求 PA0 必须是上拉输入的模式，此时 PA0 就会输出高电平。如果 PA0 不是上拉输入的模式，就会出现引脚电压不确定的错误现象。
    2. 相比第 1 种接法，多了一个上拉电阻。当按键按下时，PA0 直接接到 GND，表现为低电平；当按键松手时，引脚由于上拉作用，自然保持高电平。这种模式下不会出现引脚悬空的情况，所以此时 PA0 引脚可以配置为浮空输入或者上拉输入。
    3. 按键按下时，引脚为高电平，松手时，引脚回到默认值低电平。这要求单片机的引脚可以配置为下拉输入的模式。
    4. 按键按下时，引脚为高电平，松手时，因为下拉电阻的作用引脚回到低电平。这种连接方式要求 PA0 配置为下拉输入模式或者浮空输入模式。

STM32 中断

  • 中断：在主程序运行过程中，出现了特定的中断触发条件（中断源），使得 CPU 暂停当前正在运行的程序，转而去处理中断程序，处理完成后又返回原来被暂停的位置继续运行。
  • 中断优先级：当有多个中断源同时申请中断时，CPU 会根据中断源的轻重缓急进行裁决，优先响应更加紧急的中断源。
  • 中断嵌套：当一个中断程序正在运行时，又有新的更高优先级的中断源申请中断，CPU 再次暂停当前中断程序，转而去处理新的中断程序，处理完成后依次进行返回。

Cortex-M3 内核支持 256 个中断，其中包含了 16 个内核中断和 240 个外部中断，并且具有 256 级的可编程中断设置。

一般情况下，芯片厂商会对 Cortex-M3 的中断进行裁剪。

STM32 有 84 个中断，包括 16 个内核中断和 68 个可屏蔽中断，包含 EXTI、TIM、ADC、USART、SPI、I2C、RTC 等多个外设，具有 16 级可编程的中断优先级。

STM32F103 系列 70 个中断有 10 个内核中断和 60 个可编程的外部中断。

STM32 中断体系架构：

NVIC（Nested vectored interrupt controller 嵌套向量中断控制器）和处理器核的接口紧密相连，可以实现低延迟的中断处理和高效地处理中断。嵌套向量中断控制器管理着包括内核异常，外部中断等所有中断。由 NVIC 决定哪个中断的处理程序交给 CPU 来执行。

每一个外部中断都可以被使能或者禁止，并且可以被设置为挂起状态或者清除状态。

处理器的中断可以是电平形式的，也可以是脉冲形式的，这样中断控制器就可以处理任何中断源。

16 个 IO 的中断与 PVD(电源电压检测)，RTC(实时时钟)，USB，以太网检测这 20 个外部中断会通过外部中断控制器 EXTI 来控制，然后交给 NVIC。其他中断都是直接交给 NVIC 来处理。

中断优先级

NVIC 为了方便管理中断，可以通过软件给每个中断设置优先级。NVIC 用 4 个位来控制优先级，值小的优先级高。把优先级分为两种：抢占优先级和响应优先级。

规则：

Ø 优先级值越小，优先级越高。

Ø 如果不设置优先级，则默认优先级为 0。

Ø 先比较抢占优先级。抢占优先级高的可以打断抢占优先级低的（中断嵌套）。

Ø 若抢占优先级一样，再比较响应优先级。但是响应优先级不会导致中断嵌套。

Ø 若抢占优先级一样的同时挂起，则优先处理响应抢占优先级高的。

Ø 若挂起的优先级（抢占和响应）都一样，则查找中断向量表，值小的先响应。

NVIC 对优先级分了 5 组：

分组方式 抢占优先级 响应优先级 可用组合
分组 0 0 位，取值为 0 4 位，取值为 0~15 无抢占嵌套，16 级响应
分组 1 1 位，取值为 0~1 3 位，取值为 0~7 2 组抢占，8 级响应
分组 2 2 位，取值为 0~3 2 位，取值为 0~3 4 组抢占，4 级响应（推荐）
分组 3 3 位，取值为 0~7 1 位，取值为 0~1 8 组抢占，2 级响应
分组 4 4 位，取值为 0~15 0 位，取值为 0 16 组抢占，无响应区分（实时性高）

TIM 定时器

  • 定时器可以对输入的时钟进行计数，并在计数值达到设定值时触发中断。

  • 16 位计数器、预分频器、自动重装寄存器（计数的目标值）的时基单元，在 72MHz 计数时钟下可以实现最大 59.65s 的定时。

    1/72MHz÷(216+1)÷(216+1)≈59.65s1 / 72MHz ÷ (2^{16}+1) ÷ (2^{16}+1) ≈ 59.65s 1/72MHz÷(216+1)÷(216+1)≈59.65s

  • 不仅具备基本的定时中断功能，而且还包含内外时钟源选择、输入捕获、输出比较、编码器接口、主从触发模式等多种功能。

  • 根据复杂度和应用场景分为了高级定时器、通用定时器、基本定时器三种类型：

    类型 编号 总线 功能

基本定时器框图

  • 时基单元包含：

    1. 计数器寄存器 (TIMx_CNT)
    2. 预分频寄存器 (TIMx_PSC)
    3. 自动重装载寄存器 (TIMx_ARR)

    分频：指将一个信号的频率降低到一定比例的过程。

  • 预分频器将输入的时钟信号按设定好的倍数分频，预分频控制寄存器（TIMx_PSC）写 0 就是不分频得到 72MHz，写 1 就是二分频得到 36MHz，写 2 就是三分频得到 24MHz，依此类推（所以其值和实际系数是差 1 的）。它是一个 16 位寄存器，即最多可以分频为 65536 分之一（65535 + 1）。

  • 计数器：对预分频后的信号（CK_CNT）进行上升沿计数，每一个上升沿则计数器寄存器（TIMx_CNT）加一。当寄存器累加到规定的数目（见后自动重装载寄存器）时就触发中断，完成定时任务（加到够就跳回 0）。它也是 16 位寄存器，即最大可以从 0 数到 65535。

    这种触发的中断一般称为更新中断（Update Interrupt），即框图中的折线箭头 UI。它被送往 NVIC，之后配置好 NVIC 的定时器通道即可处理该中断；另一个向下的折线箭头 U 代表会产生一个更新事件，可以协同其它部分电路工作。

  • 自动重装载寄存器（TIMx_ARR）：它存储的就是计数器的目标值，计数器每次累加就比较二者，二者相等就触发中断，然后清零计数器寄存器。它也是一个 16 位寄存器，因为和计数器物理意义上同步相关。

  • 计算公式：

    1. 溢出频率：CK_CNT_OV=CK_PSC/(PSC+1)/(ARR+1)CK\_CNT\_OV = CK\_PSC / (PSC + 1) / (ARR + 1)CK_CNT_OV=CK_PSC/(PSC+1)/(ARR+1)
    2. 计数频率：CK_CNT=CK_PSC/(PSC+1)CK\_CNT = CK\_PSC / (PSC + 1)CK_CNT=CK_PSC/(PSC+1)
    3. 溢出时间 = 1 / 溢出频率

  • 主模式触发 DAC：DAC 是 STM32 的数模转换器外设，使用它经常会需要间隔一段固定的采样时间输出下一个电压值的情况。要完成这个操作，最基础可以用定时中断实现：即定时采样间隔，然后在中断处理中手动触发 DAC 转换，输出下一个电压值。这样的缺点也很明显，就是 CPU 会频繁地被中断。解决的方法就是中断章节中提过的事件触发方式，即 STM32 通过硬件线路，将更新事件 U 通过主模式映射到了图中的 TRGO，TRGO 直接连接到 DAC，由它去触发 DAC，不用软件干预。

  • 基本定时器只能选择内部 72MHz 时钟 CK_INT 作为时钟源。

通用计时器框图

通用计时器的计数器模式

  1. 向上计数模式：计数器从 0 计数到自动加载值 (TIMx_ARR 计数器的内容)，然后重新从 0 开始计数并且产生一个计数器溢出事件。
  2. 向下计数模式：计数器从自动装入的值（TIMx ARR 计数器的值）开始向下计数到 0，然后从自动装入的值重新开始并且产生一个计数器向下溢出事件。
  3. 中央对齐模式：计数器从 0 开始计数到自动加载的值 (TIMx_ARR 寄存器)−1，产生一个计数器溢出事件，然后向下计数到 1 并且产生一个计数器下溢事件；然后再从 0 开始重新计数。

通用计时器的时钟选择

计数器时钟可由下列时钟源提供：

  1. 内部时钟 (CK_INT)
  2. 外部时钟模式 1：外部输入脚 (TIx)
  3. 外部时钟模式 2：外部触发输入 (ETR)
  4. 内部触发输入 (ITRx)：使用一个定时器作为另一个定时器的预分频器，如可以配置一个定时器 Timer1 而作为另一个定时器 Timer2 的预分频器。（级联增大计时时间）

外部时钟模式 2：外部触发输入 (ETR)

给 TIMx_ETR 对应的引脚接入外部时钟供定时器使用，这个外部时钟也就是一个方波信号。还需要配置一下内部的“极性选择、边沿检测和预分频器”以及“输入滤波”电路。

输入滤波用于对外部电路进行一定整形，减少外部输入信号毛刺的影响。

极性选择和边沿检测用于定义触发外部中断的极性和边沿条件。在 STM32 中，通常有两种极性选项：上升沿触发、下降沿触发。常见的边沿检测选项有以下几种：上升沿和下降沿、仅上升沿、仅下降沿。

预分频器还是起分频作用，不过分配范围小一些，只能指定 1、2、4、8 分频（用两位寄存器控制）。

输入滤波和分频因子：这里用的方法是利用固定时间间隔采样，如果多次采样稳定那么说明信号稳定；如果不稳定则保持或固定某个输出，以达到一定程度滤波的效果。所以滤波器有采样频率 f 和采样点数 N 这些参数，频率越低、采样点数越多，则滤波效果越好，但相应地，信号延迟会增大。采样频率 f 可以直接来自内部时钟，也可以是内部时钟再加个分频得到——这个分频系数就是后面会提到的分频因子，即库函数那里的 ClockDivision 参数。

TIM 输出比较

输入捕获与输出比较

IC（Input Capature）输入捕获部分位于大框图左下部分，可以用于检测方波频率等。OC（Output Compare）输出比较部分对应大框图的右下部分，可以用于输出 PWM 波形驱动电机。

捕获和比较都有四条通道，对应的都是 TIMx_CH1 到 TIMx_CH4 引脚，具体哪个定时器的哪个 CH 对应的实际上的哪个引脚，查引脚复用表即可。中间的部分是捕获 / 比较寄存器 CCR，为二者共用（捕获和比较不能同时使用，所以寄存器和引脚也可以共用）。

OC（Output Compare）输出比较：通过比较 CNT 与 CCR 寄存器值的关系，来对输出电平进行置 1、置 0 或翻转的操作，用于输出一定频率和占空比的 PWM 波形。

  • CNT：时基单元计数器；

  • CCR ：Capture/Compare Register 捕获 / 比较寄存器，输入捕获电路和输出比较电路共用 CCR 寄存器。

  • 每个高级定时器和通用定时器都拥有 4 个输出比较通道。

  • 高级定时器的前 3 个通道额外拥有死区生成和互补输出的功能。

PWM 波形

PWM：Pulse Width Modulation，脉冲宽度调制。PWM 是一串数字信号，也是由高低电平组成。在具有惯性的系统中，可以通过对一系列脉冲的宽度进行调制，来等效地获得所需要的模拟参量。

直白了说就是快速、分段、不均匀地输送能量，让负载工作在完全高和完全低电平以外的中间状态，用这种方式来使数字信号达到模拟信号的等效效果（或者说其实是一个类似积分的过程）。需要强调的是一定要是具有惯性的系统，大概就是它需要自己起到一个滤波的作用。

PWM 参数：

  • 高低电平变换的周期记为 TsT_sTs​ ，其倒数 1/Ts1/T_s1/Ts​ 就称为 PWM 波形的频率。
  • 周期内高电平的时间段记为 TONT_{ON}TON​ ，低电平的时间段记为 TOFFT_{OFF}TOFF​，定义占空比为 TON/TST_{ON}/T_{S}TON​/TS​，即高电平时段在一周期内的占比。
  • 分辨率：占空比变化步距，即占空比调节的最小单位。
  • 计算平均电压：平均电压 = 峰值 × 占空比

PWM 的频率越快，等效的模拟信号就越稳，当然性能开销也就越大，一般几到几十千赫兹就差不多了。

占空比决定的是等效出的模拟电压值大小，这个关系一般是线性的。

高分辨率会对硬件电路提出要求，一般来说普通应用 1% 也就够了。

PWM 除了用于等效模拟信号，有时也可以作为通信协议（并且只需要一根线）。例如驱动舵机时，舵机会根据输入的 PWM 波形将占空比将输出轴稳定在一个角度。

TIM 输入捕获

IC（Input Capture）输入捕获模式下，当通道输入引脚出现指定电平跳变时，当前 CNT 的值将被锁存到 CCR 寄存器中，可用于测量 PWM 波形的频率、占空比、脉冲间隔、电平持续时间等参数

  • 每个高级定时器和通用定时器都拥有 4 个输入捕获通道

  • 可配置为 PWMI 模式，同时测量频率和占空比

  • 可配合主从触发模式，实现硬件全自动测量

电路分析：左下角为通用定时器的输入捕获电路，从左到右看，最左边是四个通道的引脚，查看对应芯片的引脚定义表就可以知道引脚的位置。从引脚进来有一个异或门，输入为 CH1、CH2、CH3，当这 3 个输入通道有任何一个产生电平翻转时，异或门就产生一个电平翻转。异或门的输出通过一个数据选择器接在输入捕获通道 1，当数据选择器下选择走异或门这条通路时有效，否则就走正常的 CH1 的输入捕获通道。

这个异或门其实还是为三相无刷电机服务的，无刷电机有 3 个霍尔传感器检测转子的位置，可以根据转子的位置进行换相，可以在 CH1、CH2、CH3 接上无刷电机的霍尔传感器，然后把 TMIx 作为无刷电机的接口定时器去驱动换相电路工作。

输入滤波器可以对信号进行滤波，避免一些高频的毛刺信号误触发。边沿检测器可以检测到上升沿或者下降沿，触发后续电路的动作。输入滤波器和边沿检测器有两套，以 CH1 为例，分别输出 TI1FP1 和 TI1F，TI1FP1 可以输出给通道 1，TI1FP2 可以输出给通道 2。同理，CH2 也产生两个输出，可以输出到通道 1，也可以输出到通道 2。交叉连接的作用：

  1. 可以灵活选择输入捕获电路的输入信号
  2. 可以把一个引脚的输入，同时映射到两个捕获单元（PWMI 经典结构，可以同时测量一个信号的频率和占空比）

通道 3 和通道 4 也是类似的结构。也可以选择 TRC 信号作为输入。

输入信号经过滤波和极性选择后，经过预分频器，就可以柴发捕获电路工作。每捕获一个信号，CNT 的值就想 CCR 转运一次，同时产生一个捕获事件，会在状态寄存器置标志位，同时也可以产生捕获中断。

如果要测量信号的频率，捕获信号的上升沿，相邻两个上升沿的事件就可以通过 CNT 的值配合时钟进行计算得到周期，进而得到频率。

频率的测量方法

  • 测频法通常取 T = 1s，然后测量在闸门时间内的上升沿个数（即周期个数），则频率为 N / 1 = N。测频法适合测量高频信号。
  • 测周法即根据一个已知的标准频率 fcf_cfc​，去测量两个上升沿之间的时间（即周期）N/fcN / f_cN/fc​，然后周期取倒数则得到 fX=fc/Nf_X = f_c / NfX​=fc​/N。测周法适合测量低频信号。
  • 测量总还会存在误差，不管时测频法还是测周法，误差主要来自于计次 N 的取值。取测频法和测周法的计次 N，使它们相等，得到中界频率 fmf_mfm​。当频率小于 fmf_mfm​ 时，可以认为这个信号为低频信号，适合用测周法测量，反之为高频信号，适合用测频法测量。

输入捕获通道

  • TI1：滤波器的输入信号
  • TI1F：滤波器的输出信号
  • fDTSf_{DTS}fDTS​：滤波器的采样时钟来源
  • TIMx_CCMR1 寄存器中的 ICF[3:0]位可以控制滤波器的参数，这几位定义了 TI1 输入的采样频率以及数字滤波器长度。该滤波器的工作原理是以采样频率对输入信号进行采样，当连续 N 个值都为高电平，输出才为高电平，连续 N 个值都为低电平，输出才为低电平。如果信号高频抖动，导致连续 N 个值不一样，则输出不变化。采样频率越高，采样个数越大，则滤波效果越好。
  • 信号通过边沿检测器，捕获上升沿或者下降沿，用 TIMx_CCMR 寄存器中的 CC1P 位可以选择极性。得到触发信号 TT1FP1 经过数据选择器，输出 IC1 进入通道 1 的后续捕获电路。TIMx_CCMR1 寄存器中的 CC1S 位可以对数据选择器进行选择，ICPS 位可以配置分频器，TIMx_CCMR 寄存器中的 CC1E 位，控制输出使能或失能决定 IC1PS 信号的电平高低，即 CNT 寄存器中的值是否转运到 CCR 寄存器。

这个结构可以用来测量信号频率。右上角是时基单元，配置好之后启动定时器，计数器 CNT 就会在预分频之后的时钟驱动下不断自增，CNT 为测周法提供计时，经过预分频后的时钟频率，就是驱动 CNT 的标准频率 fC=72MHz/预分频系数f_C = 72MHz / 预分频系数fC​=72MHz/预分频系数。方波信号输入 CH1 对应的 GPIO 引脚，经过滤波器和边沿检测，选择 TI1FP1 为上升沿触发。数据选择器选择 CH1 通道，分频器选择不分频。这样，当 TI1FP1 出现上升沿之后，CNT 的值就会转运到 CCR1 中，CCR1 始终保持最新一个周期的计数值。同时触发源选择 TI1FP1 为触发信号，从模式选择 Reset 复位操作，完成 CNT 的自动清零。

要注意的是，CNT 和 CCR1 的上限值为 65535，如果信号频率太低，CNT 计数值可能会溢出。

PWMI 基本结构使用两个输入捕获通道对同一个信号进行检测，可以同时测量频率和占空比。

TI1FP1 和上面一样，配置为上升沿触发，正常捕获周期和清零计数器。TI1FP2 配置为下降沿触发，通过交叉通道，去触发通道 2 的捕获单元。

从左上角的方波图看，上升沿触发时，CCR1 = CNT，CNT = 0，然后一半周期时，下降沿触发，CCR2 = CNT，CCR2 中存储的就是高电平的计数值（用于计算占空比），此时不会触发 CNT 清零，CNT 持续自增，直到下一个上升沿，CCR1 = CNT，CNT = 0。CCR1 中存储的就是一整个周期的计数值（用于计算频率）。

TIM 编码器接口

  • Encoder Interface 编码器接口
  • 编码器接口可接收增量（正交）编码器的信号，根据编码器旋转产生的正交信号脉冲，自动控制 CNT 自增或自减，从而指示编码器的位置、旋转方向和旋转速度
  • 每个高级定时器和通用定时器都拥有 1 个编码器接口
  • 两个输入引脚借用了输入捕获的通道 1 和通道 2

当编码器旋转后，A 相和 B 相就会输出这样的方波信号，方波的频率代表旋转的速度。

正转时，A 相提前 B 相 90 度，反转时，B 相提前 A 相 90 度，从而可以判断旋转方向。

编码器接口的设计逻辑是，把 A 相和 B 相的所有边沿作为计数器 CNT 的计数时钟，CNT 的增减对应正反转，通过判断另一相的状态就可以知道旋转方向。

编码器接口的输入引脚，就是定时器的 CH1 和 CH2 引脚，CH3、CH4 与编码器接口无关。

编码器接口的输出引脚，控制 CNT 计数器的增减，此时配置的 72MHz 内部时钟失效。

输入捕获的前两个通道 CH1 和 CH2 通过 GPIO 口接入编码器的 A、B 相，通过滤波器、边沿检测和极性选择，产生 TI1FP1 和 TI2FP2 作为编码器接口的输入，编码器接口通过预分频器控制 CNT 计数器的时钟，同时根据编码器的旋转方向控制 CNT 的计数方向。

一般设置 ARR 为最大量程 65535（方便利用补码的特性得到负数）。

仅在 TI1 计数的意思是只有 A 相（或 B 相）的边沿有效，忽略掉另一相的边沿。

仅在 TI2 计数同理。

ADC 模数转换器

  • ADC（Analog-Digital Converter）模拟-数字转换器

  • ADC 可以将引脚上连续变化的模拟电压转换为内存中存储的数字变量，建立模拟电路到数字电路的桥梁。

  • STM32 的 ADC 是 12 位逐次逼近型 ADC，1us 转换时间

    ADC 的两个关键参数：

    1. 分辨率（Resolution）：指 ADC 将模拟信号转换为数字信号时的精度，一般以位数表示，如 12 位、16 位等。分辨率越高，ADC 能够区分的信号细节就越多。12 位 AD 值的表示范围就是 0—212−10—2^{12}-10—212−1。
    2. 转换速率（Conversion Rate）：指 ADC 每秒钟能够完成的模拟信号转换次数，通常以赫兹（Hz）表示。转换速率越高，ADC 响应速度越快。

  • 输入电压范围：0~3.3V，转换结果范围：0~4095

  • STM32 系列 ADC 最多有 18 个输入通道，可测量 16 个外部和 2 个内部信号源

  • 规则组和注入组两个转换单元

存储器映像

内核外设指的是 NVIC 和 SysTick。

RAM（Random Access Memory）和 ROM（Read-Only Memory）都是计算机内存的类型。

RAM 是一种易失性存储器，用于临时存储计算机正在运行的程序和数据。当计算机关闭或重启时，RAM 中的数据就会丢失。RAM 的读写速度非常快，但容量通常较小。

ROM 是一种只读存储器，其中存储了固定的数据或程序，通常用于存储计算机的基本启动程序和固件。与 RAM 不同，ROM 中的数据在断电时仍然保持不变。因此，ROM 通常用于存储不需要修改的固定信息。

DMA 框图

  • 总线矩阵的左端，是主动单元，即拥有存储器的访问权；右端是被动单元，它们的存储器只能被左边的主动单元读写。

    可以看到，DMA1 有 7 个通道，DMA2 有 5 个通道，各个通道可以分别设置它们转运数据的源地址和目的地址从而各自独立工作。

  • 通道有多条，需要分时复用同一条 DMA 总线，仲裁器根据通道请求的优先级来启动外设/存储器的访问。

    在总线矩阵处也会有一个仲裁器，如果 DMA 和 CPU 都要访问同一个目标，仲裁器就会暂停 CPU 的访问以防止冲突。

  • DMA 请求就是 DMA 触发，触发源是各个外设。比如 ADC 转换完成，串口接收到数据等。需要 DMA 转运数据的时候，就通过这条线路向 DMA 发出硬件触发信号。

DMA 基本结构图

左边是外设站点，右边是存储器站点（包括 FLASH 和 SRAM）。

外设寄存器一般称为外设，所以就有了外设到存储器、存储器到外设、存储器到存储器不同分类的 DMA。

因为 Flash 是只读的，所以存储器到存储器只能是 Flash 到 SRAM 或 SRAM 到 SRAM。

【起始地址】决定了数据从哪里来，到哪里去。

【数据宽度】决定了一次转运的数据大小。可选择字节 Byte（8 位）、半字 Halfword（16 位）和字 word（32 位）。

【地址是否自增】决定了本次转运结束后，下一次转运时起始地址是否自增。

外设站点和存储器站点只有命名上的区别。实际上，也可以在外设站点中指定 Flash 或 SRAM 的地址，此时就是存储器到存储器转运的工作状态。同理，存储器站点也可以写外设的起始地址，对应外设到外设的数据转运。

传输计数器是一个自检计数器，决定了自动转运的次数。传输计数器自减到 0 以后，之前自增的地址也会恢复到起始地址的位置。

自动重装器决定了传输计数器置 0 后是否自动恢复到最初的值，即一轮工作结束后，是否立即开始下一轮的工作。

触发源有硬件触发和软件触发，由M2M（Memory to Memory）决定。

M2M 为 1 时选择软件触发，这里软件触发并不是单次触发，而是以最快的速度，连续不断的触发 DMA，直到传输计数器清零（软件触发和自动重装器不能同时使用）。软件触发一般适用于存储器到存储器的转运。

M2M 为 0 时选择硬件触发，一般都是与外设有关的转运，比如 ADC 转换完成，串口收到数据，定时时间到等。

DMA 转运的几个条件：

  1. 开关控制 ON
  2. 传输计数器 > 0
  3. 触发源必须有触发信号

【注意】写传输计数器时，必须要先关闭 DMA（开关控制 OFF）。

  1. 全双工：在全双工通信中，通信的两个节点可以同时发送和接收数据，而且数据流的方向是独立的。这意味着，每个节点都拥有自己的发送和接收信道，这两个信道可以同时工作，互不干扰。因此，全双工通信的数据传输速率比半双工更快，但需要使用更多的信号线路。
  2. 半双工：在半双工通信中，通信的两个节点不能同时发送和接收数据，而是必须交替进行。也就是说，当一个节点发送数据时，另一个节点必须处于接收状态，反之亦然。由于数据流的方向不独立，所以需要在通信的两端之间共享同一个信道。因此，半双工通信的数据传输速率比全双工慢，但只需要使用少量的信号线路。
  1. 异步通信：在异步通信中，数据的传输是不连续的，发送者和接收者之间没有任何时钟同步，数据传输的速率也可以不同。发送者和接收者之间通过握手协议（如起始位、停止位、校验位等）来确保数据的正确性，以便在数据传输过程中处理各种潜在的错误。
  2. 同步通信：在同步通信中，发送者和接收者之间有一个共同的时钟源，用于控制数据传输的速率和同步。在同步通信中，数据传输的速率是确定的，并且对于每个发送的数据块，接收方都会发出确认信号，以确保数据的完整性和正确性。

在电子电路中，"电平"通常指的是信号的电压水平或电位。而"单端"和"差分"则描述了信号的传输方式。

  1. 单端传输：在单端传输中，信号通过一个导线传输，其参考点通常是地（GND）。信号的电压相对于地的电位进行测量和传输。这种传输方式简单、成本较低，适用于许多应用，如音频信号传输、数字信号传输等。
  2. 差分传输：在差分传输中，信号传输使用两个相互补偿的导线，其中一个导线携带正向信号，另一个导线携带反向信号。差分传输的原理是通过比较两个导线上的电压差异来提取信号。这种传输方式具有抗干扰能力强、传输距离远、信号完整性高等优点，因此广泛应用于高速数据传输、长距离通信等领域。

STM32-USART 简介

  • USART（Universal Synchronous/Asynchronous Receiver/Transmitter）是一种通用的串行通信接口，常用于微控制器和外围设备之间的数据传输。它支持同步和异步的串行通信，并提供了硬件级别的数据传输和处理。

    USART 接口包括以下几个主要部分：

    1. 发送寄存器（Transmit Register）：用于将数据发送到外设或通信线路。
    2. 接收寄存器（Receive Register）：用于接收来自外设或通信线路的数据。
    3. 波特率发生器（Baud Rate Generator）：用于生成波特率时钟信号，控制数据传输速度。
    4. 控制和状态寄存器（Control and Status Register）：用于配置和监控 USART 的工作状态和传输过程。

    USART 可以通过不同的配置来实现同步或异步传输。在异步模式下，数据以字节为单位传输，每个字节由起始位、数据位、奇偶校验位和停止位组成。而在同步模式下，数据以比特流的形式传输，并使用外部时钟信号进行同步。

  • USART 是 STM32 内部集成的硬件外设，可根据数据寄存器的一个字节数据自动生成数据帧时序，从 TX 引脚发送出去，也可自动接收 RX 引脚的数据帧时序，拼接为一个字节数据，存放在数据寄存器里。

  • 自带波特率发生器，最高达 4.5Mbits/s

  • 可配置数据位长度（8/9）、停止位长度（0.5/1/1.5/2）

  • 可选校验位（无校验/奇校验/偶校验）

  • 支持同步模式、硬件流控制、DMA、智能卡、IrDA、LIN

  • STM32F103C8T6 USART 资源： USART1、 USART2、 USART3。其中 USART1 是 APB2 总线上的设备，USART2、 USART3 都是 APB1 总线上的设备。

发送器控制是用来控制发送移位寄存器工作的，接收器控制是用来控制接收移位寄存器工作的。

【硬件数据流控】也就是硬件流控制，简称流控。nRTS 和 nCTS 是 USART 接口中的硬件流控制信号。它们可以用于在数据传输过程中控制数据的流动，以避免数据丢失或错误。

  • nRTS（Request to Send）信号由发送方控制，用于告知接收方发送数据。发送方在准备好发送数据时，将 nRTS 信号置高，表示请求发送数据。接收方收到 nRTS 信号后，才会打开接收数据的通道，从而保证数据传输的顺利进行。

  • nCTS（Clear to Send）信号由接收方控制，用于告知发送方是否准备好接收数据。接收方在准备好接收数据时，将 nCTS 信号置高，表示可以接收数据。发送方收到 nCTS 信号后，才会开始发送数据，从而保证数据不会因为接收方未准备好而丢失。

【SCLK 控制】用于产生同步的时钟信号，配合发送移位寄存器输出。发送寄存器每移位一次，同步时钟电平就跳变一个周期。该时钟只支持输出，不支持输入，所以两个 USART 之间，不能实现同步的串口通信。该时钟信号用于：

  1. 兼容别的协议
  2. 可以做自适应波特率

【唤醒单元】可以实现串口挂载多设备。串口一般是点对点的通信，只支持两个设备互相通信。

【中断输出控制】配置中断是否通向 NVIC。中断申请位，就是状态寄存器这里的各种标志位。状态寄存器里有两个寄存器比较重要：

  1. TXE 发送寄存器空
  2. RXNE 接收寄存器非空

这两个是判断发送状态和接收状态的必要标志位。

【波特率发生器】实际上就是分频器，APB 时钟进行分频，得到发送和接收移位的时钟。

【USART 的起始位侦测和采样位置对齐策略】

当输入电路侦测到一个数据帧的起始位后，就会以波特率的频率，连续采样一帧数据。同时，从起始位开始，采样位置就要对齐到位的正中间。

输入电路在一位的时间长度中进行 16 次采样。

如果在某个位置突然采到一个 0，就说明在这两次之间，出现了下降沿。如果没有任何噪声，之后就是起始位。在起始位，会进行连续 16 次采样，如果没有噪声，16 次采样应该全部是 0。为了防止噪声影响，还会在下降沿的第 3 次、5 次、7 次进行一批采样，在第 8 次、9 次、10 次再进行一批采样，且这两批采样，都要要求每 3 位里面至少应有 2 个 0，才算是检测到了起始位。如果通过了起始位侦测，那么接收状态就由空闲，变为接收起始位。同时，第 8，9，10 位正好在起始位的中间，以后每一次采样也都在第 8、9、10 次进行采样，这样就能保证采样位置在位的正中间。

从 1 到 16，是一个数据位的时间长度。在一个数据位，有 16 个采样时钟，起始位侦测已经对齐了采样时钟，所以这里就直接在第 8，9，10 次采样数据位。为了保证数据的可靠性，连续采样 3 次，没有噪声的理想情况下，3 次采样应该全为 1 或者全为 0，如果有噪声，按 2：1 的规则，2 个 1 就认为收到 1，2 个 0 就认为收到 0，同时，也会置噪声标志位 NE 为 1。

I2C 通信协议

I2C（Inter-Integrated Circuit）总线是一种串行通信总线，用于连接微控制器（如单片机）、传感器、存储器芯片和其他外围设备。通过使用两根信号线（串行数据线 SDA 和串行时钟线 SCL），I2C 总线可以实现设备之间的通信和数据传输。

在一个典型的 I2C 系统中，每个设备都有一个唯一的地址，通过该地址来识别设备。主控制器（通常是微控制器）负责发起通信并控制总线上的所有设备。通过发送起始条件、地址、数据和停止条件的序列，主控制器可以与特定设备进行通信。

I2C 总线具有一些优点，例如占用引脚少、支持多主设备、可通过外部电阻调节传输速率等。但它也有一些局限性，如通信速率相对较低、总线长度受限等。

  • 两根通信线：SCL（Serial Clock）、SDA（Serial Data）
  • 同步，半双工
  • 带数据应答
  • 支持总线挂载多设备（一主多从、多主多从）

硬件电路

  • 所有 I2C 设备的 SCL 连在一起，SDA 连在一起
  • 设备的 SCL 和 SDA 均要配置成开漏输出模式
  • SCL 和 SDA 各添加一个上拉电阻，阻值一般为 4.7KΩ左右

左边的图是一个 I2C 的典型电路模型，是一个一主多从模型。

  • 任何时候，都是主机完全掌控 SCL 线。

  • 在空闲时，主机可以主动发起对 SDA 的控制。只有在从机发送或者从机应答的时候，主机才会将 SDA 的控制权交给从机。

  • 从机可以是姿态传感器、OLED、存储器、时钟模块等等。

  • I2C 禁止所有设备输出强上拉的高电平，采用外置若上拉电阻+开漏输出的电路结构。

I2C 时序基本单元

  • 起始条件：SCL 高电平期间，SDA 从高电平切换到低电平
  • 终止条件：SCL 高电平期间，SDA 从低电平切换到高电平

起始和终止条件都是由主机产生的，从机不允许产生起始和终止。

  • 发送一个字节：

    1. SCL 低电平期间，主机将数据位依次放到 SDA 线上（高位先行）
    2. 然后释放 SCL，从机将在 SCL 高电平期间读取数据位

    所以 SCL 高电平期间 SDA 不允许有数据变化，依次循环上述过程 8 次，即可发送一个字节

主机如果想要发送 0，就在 SCL 为低电平期间将 SDA 置为低电平；如果想要发送 1，就在 SCL 为低电平期间将 SDA 置为高电平。之后主机释放 SCL，从机在 SCL 高电平期间读取。

  • 接收一个字节：SCL 低电平期间，从机将数据位依次放到 SDA 线上（高位先行），然后释放 SCL，主机将在 SCL 高电平期间读取数据位，所以 SCL 高电平期间 SDA 不允许有数据变化，依次循环上述过程 8 次，即可接收一个字节（主机在接收之前，需要释放 SDA 给从机）

从流程上看，接收一个字节和发送一个字节是非常相似的，区别就是发送一个字节是低电平主机放数据，高电平从机读数据，而接收一个字节是电平从机放数据，高电平主机读数。

  • 发送应答：主机在接收完一个字节之后，在下一个时钟发送一位数据，数据 0 表示应答，数据 1 表示非应答

  • 接收应答：主机在发送完一个字节之后，在下一个时钟接收一位数据，判断从机是否应答，数据 0 表示应答，数据 1 表示非应答（主机在接收之前，需要释放 SDA）

I2C 时序

  • 指定地址写
  • 对于指定设备（Slave Address 从机地址），在指定地址（Reg Address 寄存器地址）下，写入指定数据（Data）

起始条件后，主机发送一个字节数据（7 位从机地址+1 位读写位），从机地址决定要通信的设备，读写位决定主机是要读（1）还是写（0）。

根据协议，紧接着的单元应该是从机的应答位。此时主机释放 SDA，从机下拉 SDA，主机在 SCL 高电平时读取 SDA 为 0，即接收到从机应答。然后从机释放 SDA。

从机设备可以自己定义第二个字节和后续字节的用途，一般第二个字节可以是寄存器地址或者指令控制字。比如 MPU6050 定义的第二个字节就是寄存器地址，而 AD 转换器第二个字节可能就是指令控制字。

重复这个过程发送数据。当主机发送数据结束时，就在 SCL 低电平时先拉低 SDA，然后释放 SCL，再释放 SDA，满足结束条件：SCL 高电平期间，SDA 从低电平切换到高电平。通信结束。

  • 对于指定设备（Slave Address），在当前地址指针指示的地址下，读取从机数据（Data）

开始：SCL 高电平期间，主机拉低 SDA，产生开始条件

接收从机应答位，从机应答 0，代表从机收到了一个字节

SPI 通信协议

SPI（Serial Peripheral Interface）通信协议是一种用于在微控制器和外部设备之间进行串行数据传输的通信协议。它通常用于短距离、高速、同步、全双工的通信传输。

SPI 通信协议包含四根信号线：

  1. SCK（Serial Clock）：时钟线，由主设备产生，控制数据传输速度。
  2. MOSI（Master Output Slave Input）：主设备输出从设备输入线，即主设备将数据传输至从设备的数据输入端。
  3. MISO（Master Input Slave Output）：主设备输入从设备输出线，即从设备将数据传输至主设备的数据输出端。
  4. SS（Slave Select）：从设备选择线，由主设备控制，选择需要进行通信的从设备。

硬件电路

  • 所有 SPI 设备的 SCK、MOSI、MISO 分别连在一起

  • 主机另外引出多条 SS 控制线，分别接到各从机的 SS 引脚。主机想控制那个从机，就拉低对应的 SS 线。

  • 输出引脚配置为推挽输出，输入引脚配置为浮空或上拉输入

  • SPI 所有通信线都是单端信号，它们的高低电平都是相对 GND 的电压差。所以，单端信号，所有的设备还需要共地（图中 GND 没有画出来）。

  • 如果从机没有独立供电，主机还需要额外引出电源正极 VCC 给从机供电。

移位示意图

SPI 通信一般都是高位先行，所以每来一个时钟，移位寄存器都会向左进行移位。

移位器中的时钟源是由主机提供的，这里叫作波特率发生器。它产生的时钟驱动主机的移位寄存器进行移位，同时，这个时钟也通过 SCK 引脚进行输出，接到从机的移位寄存器里。

主机移位寄存器左边移出去的数据，通过 MOSI 引脚，输入到从机移位寄存器的右边。

从机移位寄存器左边移出去的数据，通过 MISO 引脚，输入到主机移位寄存器的右边。

这样构成一个圈。

规定：波特率发生器时钟的上升沿，所有移位寄存器向左移动一位，移出去的位放到引脚上。波特率发生器时钟的下降沿，引脚上的位，采样输入到移位寄存器的最低位。这个过程进行 8 次，完成主机和从机一个字节数据的交换。

SPI 通信的基础就是交换一个字节。可以实现发送一个字节，接收一个字节，发送并接收一个字节。

SPI 时序基本单元

  • 起始条件：SS 从高电平切换到低电平

  • 终止条件：SS 从低电平切换到高电平

模式 0 用得最多。当 SS 为高电平时，默认 MISO 为高阻态。SCK 第一个边沿移入数据，意味着在 SCK 第一个上升沿之前，就要先移出数据。所以当 SS 为低电平选中从设备的时候，主设备和从设备的第一个字节的高位数据已经在引脚上了。

SPI 时序

  • 发送指令（发送的第一个字节数据通常为指令）
  • 向 SS 指定的设备，发送指令（0x06）

在空闲状态，SS 为高电平，SCK 为低电平，MOSI 和 MISO 的默认电平没有严格规定。然后，SS 产生下降沿，时序开始，MOSI 第一个电平是低电平，所以 MOSI 没有变化。W25Q64 不需要回传数据时，手册里规定的是 MISO 仍然是高阻态，从机并没有开启输出，因为 STM32 的 MISO 是上拉输入，所以这里 MISO 呈现高电平。

SCK 的第一个上升沿进行数据移入。从机采样输入，得到 0，主机采样输入，得到 1。

下降沿数据移出，上升沿数据移入，重复这个过程，交换一个字节 8 位数据。

SS 置为高电平，结束通信。主机用 0x06 换来了从机的 0xFF。

  • 指定地址写
  • 向 SS 指定的设备，发送写指令（0x02），随后在指定地址（Address[23:0]）下，写入指定数据（Data）

地址为 24 位，分 3 个字节发送。

  • 指定地址读
  • 向 SS 指定的设备，发送读指令（0x03），随后在指定地址（Address[23:0]）下，读取从机数据（Data）

SPI 框图

  • LSBFIRST 给 1 是低位先行，给 0 是高位先行

  • 缓冲区是数据寄存器 DR，发送缓冲区是发送数据寄存器 TDR，接收缓冲区就是接收数据寄存器 RDR。TDR 和 RDR 占用同一个地址，统一称为 DR。

  • 数据寄存器和移位寄存器配合可以实现连续的数据流：比如，STM32 作为主机需要发送一批数据。

    • 第一个数据先写入 TDR，当移位寄存器没有数据移位时，TDR 的数据会立刻转入移位寄存器，开始移位。这个转入时刻，会置状态寄存器的 TXE 为 1，表示发送寄存器空。当我们检查 TXE 置 1 时，就可以将下一个数据提前写入到 TDR 中等候。
    • 移位寄存器会根据时钟将数据一位一位的移出到 MOSI 引脚，在移出的过程中，MISO 的数据也会移入，一旦数据移出完成，数据的移入也完成了。再将移入的数据整体地转入到接收缓冲区 RDR，这个时刻会置状态寄存器的 RXNE 为 1，表示接收缓冲区非空，当我们检查到 RXNE 置 1 后，就要尽快把数据从 RDR 中读出来。在下一个数据来之前，读出 RDR，就可以实现连续接收。

  • SPI 是全双工，发送和接收同步进行，所以数据寄存器分为发送和接收两部分，而移位寄存器发送和接收可以共用。

    I2C 是半双工，发送和接收不会同时进行，所以数据寄存器和移位寄存器在发送和接收时可以共用。

    串口是全双工，发送和接收可以异步进行，所以发送和接收的数据寄存器和移位寄存器都是分离的。

  • 波特率发生器主要来产生内部时钟，输入时钟是 PCLK，频率为 72M 或 36M，经过分频器后，输出到 SCK 引脚。每产生一个时钟，移入或移出一个 bit。右边 CR1 寄存器的 3 个位 BR0，BR1，BR2 用来控制分频系数

  • SPE：SPI 使能，就是 SPI_Cmd 函数配置的位

  • MSTR：配置主从模式，1 是主模式，0 是从模式

  • CPOL 和 CPHA 用来选择 SPI 的四种模式。

  • NSS 引脚主要用来实现多主机模型，不是 SPI 通信协议中的 SS，SS 用一个 GPIO 模拟。

时序图-主模式全双工连续传输

传输更快，操作复杂：

  • CPOL=1，CPHA=1，默认配置位模式 3，SCK 默认高电平。然后在第一个下降沿，MISO 和 MOSI 移出数据，上升沿移入数据，循环往复。
  • 第 2 行是 MISO 和 MOSI 输出的波形，跟随 SCK 变化。
  • 第 3 行是 TXE，发送寄存器 TDR 空标志位。
  • 第 4 行是发送缓冲器（写入 SPI_DR），实际上就是发送寄存器 TDR。
  • 第 5 行 BSY 忙标志位是由硬件自动设置和清除的，当有数据传输时，BSY=1.
  • 第 2，3，4 行演示的是输出时的流 v 程和现象，第 6，7，8 演示的则是输入时的流程和现象。
  • 第 6 行是 MISO 和 MOSI 输入的波形，跟随 SCK 变化。
  • 第 7 行是 RXNE，接收寄存器 RDR 空标志位。
  • 第 8 行是接收缓冲器（写入 SPI_DR），实际上就是发送寄存器 TDR。

首先，SS 置低电平开始时序（图中没画）。在刚开始是，TXE=1，表示 TDR 为空可以写入数据。此时，软件写入第一个数据 0XF1 到 TDR，然后 TXE=0。TDR 是等候区，移位寄存去才是真正的发送区。

移位寄存器刚开始为空，当 0xF1 写入到 TDR 后，会立刻转移到移位寄存器开始发送，转入瞬间 TXE=1。

转入移位寄存器后，数据 F1 的波形就开始产生了。为了连续传输，当 TXE=1 后，我们就写入 0xF2 到 SPI_DR 等候。F2 转移到移位寄存器后，再将 F3 写入 SPI_DR 等待。发送 3 个字节后结束，TXE 标志位始终为 1，此时还需要等待 F3 的数据波形完全发送完成，BSY 标志位再由硬件置 0。这就是发送的流程。

SPI 是全双工，发送的同时，还有接收。可以看到，在第一个字节 F1 发送完成以后，也同时接收完成一个字节 A1。A1 接收完成后，整体由移位寄存器转入到 RDR，转入的同时，RXNE 标志位也置 1，表示收到数据了。然后软件读出数据 A1，清除标志位 RXNE。当下一个数据 A2 收到后，RXNE 重新置 1，重复这个过程。需要注意的是，一个字节的数据收到后，移位寄存器的数据自动转入 RDR，会覆盖原有的数据，故读出 RDR 要及时。

连续传输对软件的要求比较高，在每个标志位产生后，数据都要及时进行处理。

时序图-非连续传输

非连续，简单，易于封装，好用：

CPOL=1，CPHA=1，默认配置位模式 3，SCK 默认高电平。想发送数据时，如果检测到 TXE=1（TDR 为空），就软件写入 0xF1 到 SPI_DR（也就是 TDR），此时 TDR 的值变为 F1，TXE=0。目前移位寄存器也是为空，所以这个 0xF1 会立刻转入移位寄存器开始发送，并且 TXE=1，表示可以把下一个数据放在 TDR 中等候。

为了简化流程，当 TXE=1 时，我们不着急把下一个数据写进去，而是一直等待，等到第一个字节发送时序结束，此时意味着接收第一个字节也结束了。这时 RXNE=1，我们等待 RXNE=1 后，把接收到的数据读出（指交换数据时从机发过来的数据），然后再把第二个数据写入。

重复这个过程。

按照这种非连续传输的方法，字节与字节之间有间隙，在 SCK 频率变高时这个间隙会变得越来越明显，所以这种非连续传输的方法，不适合 SCK 频率高的情况。

  • Unix 时间戳（Unix Timestamp）定义为从 UTC/GMT 的 1970 年 1 月 1 日 0 时 0 分 0 秒开始所经过的秒数，不考虑闰秒。

  • 时间戳存储在一个秒计数器中，秒计数器为 32 位/64 位的整型变量。世界上所有时区的秒计数器相同，不同时区通过添加偏移来得到当地时间。

  • UTC（Universal Time Coordinated）协调世界时是一种以原子钟为基础的时间计量系统。它规定铯 133 原子基态的两个超精细能级间在零磁场下跃迁辐射 9,192,631,770 周所持续的时间为 1 秒。当原子钟计时一天的时间与地球自转一周的时间相差超过 0.9 秒时，UTC 会执行闰秒来保证其计时与地球自转的协调一致。

  • 用户数据存储容量： 20 字节（中容量和小容量）/ 84 字节（大容量和互联型）

橙色区域可以叫做后备区域，BKP 处于后备区域，但后备区域不止有 BKP，还有 RTC 的相关电路。

后备区域的特性就是，当 VDD 主电源掉电后，后备区域仍然可以由 VBAT 的备用电池供电，当 VDD 主电源上电时，后备区域会由 VBAT 切换到 VDD。

BKP 中主要有数据寄存器、控制寄存器、状态寄存器、RTC 时钟校准寄存器。

数据寄存器时主要备份，用来存储数，每个数据寄存器都是 16 位的，即一个数据寄存器可以存 2 个字节。

图的左边：

  • 可以从 PC13 的 TAPMPER 引脚引入一个检测信号，当 TAMPER 产生上升沿或者下降沿时，清除 BKP 所有的内容，以保证安全。

  • 时钟输出，可以把 RTC 的相关时钟，从 PC13 位置的 RTC 引脚输出出去，供外部使用。

RTC 简介

  • RTC（Real Time Clock）实时时钟。

  • RTC 是一个独立的定时器，可为系统提供时钟和日历的功能。

  • RTC 和时钟配置系统处于后备区域，系统复位时数据不清零，VDD（2.0~3.6V）断电后可借助 VBAT（1.8~3.6V）供电继续走时。

  • 32 位的可编程计数器，可对应 Unix 时间戳的秒计数器。

  • 20 位的可编程预分频器，可适配不同频率的输入时钟。

    RTCCLK 的时钟频率一般较大，为了满足 32 位可编程计数器 1Hz 的时钟频率要求，设置了一个 20 位的 RTC 预分频器。

  • 可选择三种 RTC 时钟源接入 RTCCLK：

    • HSE 时钟除以 128（通常为 8MHz/128）
    • LSE 振荡器时钟（通常为 32.768KHz）
    • LSI 振荡器时钟（40KHz）

    HSE=高速外部时钟信号
    HS=高速内部时钟信号
    LS=低速内部时钟信号
    LSE=低速外部时钟信号

RTC 框图

灰色填充的部分都处于后备区域，这些电路在主电源掉电后，可以使用备用电池维持工作。

RTCCLK 的来源需要在 RCC 里面进行配置，经过 RTC 预分频器进行分频。这个预分频器由两个寄存器组成，上面的 RTC_PRL 是重装载寄存器，下面的 RTC_DIV 手册里面叫余数寄存器。它们两个之间的关系和定时器计数器 CNT 和重装值 ARR 是一样的作用，RTC_PRL 就是计数目标，写入 6 就是 7 分频，写入 9 就是 10 分频（计数器包含 0，所有实际分频要加一）；这里的 RTC_DIV 是一个递减寄存器，每来一个上升沿，DIV 减一，DIV 递减到 0 时，此时再来一个时钟沿，DIV 就输出一个脉冲，产生溢出信号，同时从 PRL 那里获取新的重装值。

32 位可编程计数器可以看作是 Unix 时间戳的秒计数器，借助 time. h 库可以很方便地得到年月日时分秒。RTC_ALR 是一个闹钟计时器，也是 32 位的，作用是设置闹钟。可以再 RTC_ALR 中设置秒数，当 CNT 中的值和 ALR 中的值一样时，就会产生 RTC_Alarm 信号，通往右边的中断系统。闹钟和 WKUP 引脚都可以唤醒待机模式。

除此之外，RTC_Second 就是每秒进一次中断，RTC_Overflow 当 CNT 溢出时发生中断（一般不会发生）。RTC 中断控制中，以 F（Flag）结尾的就是中断控制标志位，以 IE（Interrupt Enable）结尾的是中断使能。3 个信号通过一个或门（图中少画一个信号的线）汇聚到 NVIC 中断控制器。

RTC 是 APB1 上的设备，读写 RTC 相关的寄存器要通过 APB1 总线。

RTC 注意事项

写代码时要注意：

  • 执行以下操作将使能对 BKP 和 RTC 的访问：
    1. 设置 RCC_APB1ENR 的 PWREN 和 BKPEN，使能 PWR 和 BKP 时钟
    2. 设置 PWR_CR 的 DBP，使能对 BKP 和 RTC 的访问
  • 若在读取 RTC 寄存器时，RTC 的 APB1 接口曾经处于禁止状态，则软件首先必须等待 RTC_CRL 寄存器中的 RSF 位（寄存器同步标志）被硬件置 1
  • 必须设置 RTC_CRL 寄存器中的 CNF 位，使 RTC 进入配置模式后，才能写入 RTC_PRL、RTC_CNT、RTC_ALR 寄存器
  • 对 RTC 任何寄存器的写操作，都必须在前一次写操作结束后进行。可以通过查询 RTC_CR 寄存器中的 RTOFF 状态位，判断 RTC 寄存器是否处于更新中。仅当 RTOFF 状态位是 1 时，才可以写入 RTC 寄存器
