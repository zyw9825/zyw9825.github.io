Graphics View 的构成

Qt 为绘制复杂的可交互图形提供了 Graphics View 绘图架构，是一种基于图形项（Graphics Item）的模型/视图模式，与 Model/View 模式类似。

Graphics View 绘图架构主要由 3 部分组成：场景、视图与图形项。

  1. 场景 Scene

    场景不可见，是一个抽象的管理图形项的容器。主要有以下功能：

    • 提供管理大量图形项的快速接口
    • 将事件传播到每个图形项
    • 管理每个图形项的状态
    • 管理未经变换的渲染功能，主要用于打印

    除了图形项以外，场景还有背景层和前景层，通常由 QBrush 指定，也可以重写 drawBackground() 和 drawForeground() 函数来实现自定义的背景和前景。

  2. 视图 View

    视图组件用于显示部分场景中的内容，可以为一个场景设置多个视图。在图中，虚线框的部分是一个场景，视图 1 比场景大，显示场景的全部内容。默认情况下：

    • 当视图大于场景时，场景在视图的中间部分显示，也可以设置视图的 Alignment 属性控制场景在视图中的显示位置；
    • 当视图小于场景时（视图 2），视图只能显示场景的一部分内容，但是会自动提供滚条在整个场景内移动。

    视图接收键盘和鼠标输入并转换为场景事件，并进行坐标转换后传送给可视场景。

  3. 图形项 Graphic Item

    基本的图形元件，其基类是 QGraphicsItem。Qt 提供了一些基本的图形项，如绘制椭圆的 QGraphicsEllipseItem、绘制矩形的 QGraphicsRectItem、绘制文字的 QGraphicsTextItem 等。图形项支持以下一些操作：

    • 支持鼠标事件响应
    • 支持键盘事件响应
    • 支持拖放操作
    • 支持组合，可以是父子项关系组合，也可以是通过 QGraphicsItemGroup 类进行组合

    所以，图形项可以被选择、拖放、组合，可以通过编写信号/槽函数代码实现各种编辑功能。一个图形项还可以包含子图形项，支持碰撞检测。

Graphics View 的坐标系统

  1. 图形项坐标

    图形项使用自己的局部坐标（Item Coordinates），其中心坐标为（0,0），也是各种坐标变换的中心。图形项的鼠标事件的坐标也是用局部坐标表示的。

    创建自定义图形项时，只需要考虑其局部坐标，QGraphicsScene 和 QGraphicsView 会自动进行坐标转换。

    一个图形项的位置是其中心点在父坐标系统中的坐标，父坐标系统默认是其父图形项的局部坐标，也可以是场景坐标（若无父图形项）。QGraphicsItem:pos()：返回该图形项在父项中的局部坐标位置。

    父项进行坐标变换时，子项也做同样的坐标变换。

    QGraphicsItem 的大多数函数都是在其局部坐标系上操作的，QGraphicsItem:boundingRect()：返回图形项在其局部坐标系中的边界矩形。

  2. 视图坐标

    视图坐标（View Coordinates）就是窗口界面（widget）的物理坐标，单位是像素。

    视图坐标只与 widget 或视口有关，而与观察的场景无关。

    QGraphicsView 视口的左上角坐标总是（0,0）。

    [!NOTE]

    所有的鼠标事件、拖放事件的坐标首先是由视图坐标定义的，然后用户需要将这些坐标映射为场景坐标，以便和图形项交互。

  3. 场景坐标

    场景是所有图形项的基础坐标，场景坐标（Scene Coordinates）描述了每个顶层图形项的位置。

    场景坐标系的原点 (0, 0) 通常位于场景的左上角。

    创建场景时可以指定坐标范围，比如：

    QGraphicsItem::scenePos() 返回图形项相对于整个场景（scene）的全局坐标位置。

    QGraphicsItem::sceneBoundingRect() 返回图形项在整个场景坐标系中的边界矩形。通常用于碰撞检测、视图更新和其他需要知道图形项在场景中确切位置和大小的场合。

    场景中的任何图形项的边界矩形发生变化时会发射 QGraphicsScene:changed() 信号，参数是一个场景的矩形列表，表示发生变化的矩形区。

  4. 坐标映射
    在场景中操作图形项时，进行场景到图形项、图形项到图形项，或视图到场景之间的坐标变换是比较有用的，即坐标映射（Coordinate Mapping）。

    例如，在 QGraphicsView 的视口上单击鼠标时，通过函数 QGraphicsView:mapToScene() 可以将视图坐标映射为场景坐标，然后用 QGraphicsScene:itemAt() 函数可以获取场景中鼠标光标处的图形项。

Graphics View 相关的类

Graphics View 结构的主要类包括：

  • 视图类 QGraphicsView
  • 场景类 QGraphicsScene
  • 各种图形项类，其父类都为 QGraphicsItem

QGraphicsView 类主要函数

视图 QGraphicsView 是用于观察场景的物理窗口。QGraphicsView 类主要的函数如下：

场景相关：

  • void setScene(QGraphicsScene *scene) 设置关联显示的场景
  • void setSceneRect(const QRectF &rect) 设置场景在视图中的可视部分的矩形区域

外观相关：

交互相关：

  • void setInteractive(bool allowed) 设置是否开启交互，如果禁止交互，则鼠标、键盘等操作会忽略
  • QRect rubberBandRect() const 返回选择矩形框
  • void setRubberBandSelectionMode(Qt::ItemSelectionMode mode) 设置橡皮筋选择模式
  • QGraphicsItem* itemAt() 获取视图坐标系中某个位置处的图形项（多个实现）
  • QList<QGraphicsltem*> items() 获取场景中的所有、或者某个选择区域内图形项的列表（多个实现）

坐标映射：

  • QPoint mapFromScene() 将场景中的一个坐标转换为视图的坐标
  • QPointF mapToScene() 将视图中的一个坐标转换为场景的坐标

QGraphicsItem 主要函数

QGraphicsItem是所有图形项的基类，用户也可以从QGraphicsItem继承定义自己的图形项。Ot定义了一些常见的图形项，这些常见的图形项的类的继承关系如图所示。

类提供了图形项操作的函数，主要如下：

属性设置：

  • void setFlags() 设置图形项的操作属性，例如，可选择、可移动等
  • void setOpacity() 设置透明度
  • void setGraphicsEffect() 设置图形效果（模糊、阴影等）
  • void setSelected() 图形项是否被选中
  • void setData() 用户自定义数据

坐标：

  • void setX() 图形项的X坐标
  • void setY() 图形项的Y坐标
  • void setZValue() 图形项的Z值，Z值控制图形项的叠放次序
  • void setPos() 图形项在父项中的位置
  • QPointF scenePos() 返回图形项在场景中的坐标，相当于调用mapToScene(0,0)

坐标变换：

  • void resetTransform() 复位坐标系，取消所有坐标变换
  • void setRotation() 旋转一定角度，参数为正数时表示顺时针旋转
  • void setScale() 按比例缩放，缺省值为1

坐标映射：

  • QPointF mapFromltem() 将另一个图形项的一个点映射到本图形项的坐标系
  • QPointF mapFromParent() 将父项的一个点映射到本图形项的坐标系
  • QPointF mapFromScene() 将场景中的一个点映射到本图形项的坐标系
  • QPointF mapToltem() 将本图形项内的一个点映射到另一个图形项的坐标系
  • QPointF mapToParent() 将本图形项内的一个点映射到父项坐标系
  • QPointF mapToScene() 将本图形项内的一个点映射到场景坐标系
