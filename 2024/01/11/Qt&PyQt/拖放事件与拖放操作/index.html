拖拽事件和拖放操作

发表于2024-01-11|更新于2024-01-11|Qt
|总字数:3.3k|阅读时长:13分钟|浏览量:

概述

拖放提供了一种简单的可视化机制，用户可使用它在应用程序之间和内部传输信息。

拖放由两个操作组成：拖动（drag）和放置（drop）。被拖动的组件称为拖动点（drag site），接收拖动操作的组件称为放置点（drop site）。

[!NOTE]

拖动点和放置点可以是同一个组件，也可以是不同的组件，甚至可以是不同的应用程序。

整个拖动操作可以分解为两个过程：

  1. 拖动点启动拖动操作。

    一般情况下，当检测到鼠标左键按下就可以启动拖动操作，可以通过重写被拖动组件的 mousePressEvent() 和 mouseMoveEvent() 函数来启动拖动。

    启动操作需要创建一个 QDrag 对象描述拖动操作，以及创建一个 QMimeData 对象用于存储拖动操作的格式信息和数据，然后将该 QMimeData 对象赋值给 QDrag 对象的 mimeData 属性。

  2. 放置点处理放置操作。

    当拖动点被拖动到放置点范围内时，触发 dragEnterEvent() 事件处理函数，一般在该函数中通过 QDrag 对象的 mimeData 属性判断拖动操作的来源和参数，以决定是否接受此拖动操作。

    该拖动操作被接受后触发 dropEvent() 事件处理函数，用于处理放置时的具体操作。

要实现完成的拖放操作需要对各种事件进行处理，拖动点和放置点最好是各自实现相关事件处理的类。如果要在同一个窗口上实现这些事件的处理，需要用到事件过滤器。

[!Note]

哪些组件可以作为放置点/拖动点？

QWidget 类有一个 acceptDrops 属性，设置为 True 时对应的组件就可以当作一个放置点。

QWidget 类中没有定义拖动操作相关的函数，所以一般界面组件时不能作为拖动点的。但可以通过重写 QWidget 的鼠标事件（如 mousePressEvent, mouseMoveEvent, 和 mouseReleaseEvent）等来实现 QWidget 的拖动功能。

QAbstractItemView 类定义了更多与操作有关的函数，所以，QListWidget，QTreeWidget，QTableWidget 等组件既可以作为拖动点，也可以作为放置点。

与拖动相关的全局参数

QStyleHints 对象提供了一些与拖放操作相关的属性：

  • startDragTime() 开始拖动前必须在对象上按住鼠标按钮的事件（以毫秒为单位）。

  • startDragDistance() 表示用户在按住鼠标按钮的情况下必须移动鼠标多远才会被解释为拖动。

  • startDragVelocity() 表示用户必须以多快的速度（以像素/秒为单位）移动鼠标才能开始拖动。值为 0 表示没有这样的限制。

QStyleHints 的实例对象来自 QGuiApplication，用于访问某些 GUI 全局参数。

拖动点 drag site

拖放是用户在应用程序中复制或移动数据的一种直观方式，在许多桌面环境中用作在应用程序之间复制数据的机制。QDrag 类是 Qt 中支持拖放操作的核心类，用于处理拖放操作的大部分细节。

拖放从 QDrag 对象的 exec() 的函数开始，习惯上，当在组件上按下鼠标并将光标移动一段距离时视为开始拖放。所以，如果想要某个组件能够被拖放，最简单的方法就是重写组件的 mousePressEvent()，在这里开始拖放操作。

mousePressEvent 方法在鼠标按钮按下时被调用。你可以在这个方法中捕获鼠标按下的事件，并执行相应的操作。

exec() 函数是一个阻塞函数，但不会阻塞主事件循环，它的返回值是一个枚举类型 enum Qt::DropAction，表示拖放操作的结果：

Constant Value Description
Qt::CopyAction 0x1 Copy the data to the target.
Qt::MoveAction 0x2 Move the data from the source to the target.
Qt::LinkAction 0x4 Create a link from the source to the target.
Qt::ActionMask 0xff
Qt::IgnoreAction 0x0 Ignore the action (do nothing with the data).
Qt::TargetMoveAction 0x8002

通过第一个参数 supportedActions 可以指定拖放操作支持哪些动作（例如复制、移动、链接等），默认为支持移动即 MoveAction，还可以指定一个额外参数 defaultDropAction 设置默认的动作。

QDrag 类还提供了其它函数来支持拖放操作：

  • setMimeData() 和 mimeData() ：设置或返回与拖动关联的 QMimeData 对象。
  • setPixmap() 和 pixmap()：设置或返回拖动过程中的显示图标。
  • setHotSpot() 和 hotSpot()：设置或返回拖动图像的热点。热点是指图像中与鼠标指针对齐的点。
  • dragCursor() 和 setDargCursor() : 设置或返回光标。
  • source(): 获取启动拖动操作的对象，即发起拖动操作的控件（QObject）。
  • target() 返回拖放操作的目标。这是拖放对象被放置到的窗口小部件。

QMimeData 类

通过拖放操作传输的数据包含在 QMimeData 对象中，通过 setMimeData() 方法设置。QMimeData 类是 Qt 框架中用于处理数据传输的类，特别是在拖放操作和剪贴板操作中。它可以存储任意格式的数据，包括文本、HTML、URL、图像等。

单个 QMimeData 对象可以同时使用几种不同的格式存储相同的数据，formats() 函数按优先顺序返回可用格式的列表。data() 函数返回与 MIME 类型相关的原始数据，并且 setData() 允许设置 MIME 类型的数据。

对于最常见的 MIME 类型，QMimeData 类提供了方便的 Setter 、Getter 和 Tester ()方法：

Tester Getter Setter MIME Types
hasText() text() setText() text/plain
hasHtml() html() setHtml() text/html
hasUrls() urls() setUrls() text/uri-list
hasImage() imageData() setImageData() image/*
hasColor() colorData() setColorData() application/x-color

[!NOTE]

MIME 类型（Multipurpose Internet Mail Extensions）用于描述网络上传输的各种文件类型。每个 MIME 类型包含两部分：类型和子类型，中间用斜杠（/）分隔。例如，text/plain 表示纯文本文件，image/jpeg 表示 JPEG 图像文件。
