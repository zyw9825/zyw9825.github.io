numpy 数组基础

NumPy’s array class is called ndarray. It is also known by the alias array.

数组的属性

  • ndarray.ndim：the number of axes (dimensions) of the array.

  • ndarray.shape：the dimensions of the array. This is a tuple of integers indicating the size of the array in each dimension.

    ndim 是数组维度（轴）的数量，shape 是数组的维度。

    shape 会返回一个元组，元组中的每一个元素对应着每一维度的大小(size)。

    对于一个 3×5 的二维数组来说，shape 就是 (3,5)，也就是说，数组的第一个维度有 3 个元素，数组的第二个维度有 5 个元素。

    ndim 是数组的维度个数，二维数组的 ndim 就是 2，三维数组就是 3。

    如果一个数组的 shape 是(1,2,3,4)，说明这是一个 4 维数组，第一维度有 1 个元素，第二维度有 2 个元素，第三维度有 3 个元素，第 4 维度有 4 个元素。

  • ndarray.size：the total number of elements of the array. This is equal to the product of the elements of shape.

  • ndarray.itemsize：the size in bytes of each element of the array.

    前者是数组的大小（元素个数），后者是数组中元素的大小（字节）。

    还有一个 nbytes 的属性表示数组的总字节大小，

  • ndarray.dtype：an object describing the type of the elements in the array.

  • ndarray.data：the buffer containing the actual elements of the array.

    这个属性一般不使用，通常情况下使用索引来访问数组中的元素。

numpy 通用函数

  • Python 在处理某些操作时非常慢，一部分原因是该语言的动态性和解释性。

  • NumPy 为很多类型的操作提供了非常方便的、静态类型的、可编译程序的接口，也被称作向量操作。

  • NumPy 中的向量操作是通过通用函数实现的。通用函数的主要目的是对 NumPy 数组中的值执行更快的重复操作。

数组的运算

  • 通用函数有两种存在形式：一元通用函数（unary ufunc）对单个输入操作，二元通用函数（binary ufunc）对两个输入操作。

广播的规则

  • 规则 1：如果两个数组的维度数不相同，那么小维度数组的形状将会在最左边补 1。

  • 规则 2：如果两个数组的形状在任何一个维度上都不匹配，那么数组的形状会沿着维度为 1 的维度扩展以匹配另外一个数组的形状。

  • 规则 3：如果两个数组的形状在任何一个维度上都不匹配并且没有任何一个维度等于 1，那么会引发异常。

    • a.shape 是(3,)，即 a 是一维数组，有 3 个元素

    根据规则 1，a 的维度小，所以在最左边补1：a.shape 变为(1,3)；

    根据规则 2 ，两个数组第一维度不匹配，因此扩展这个维度以匹配，所以a.shape 变为(2,3)。
