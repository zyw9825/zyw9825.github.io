Makefile

参考资料：陈皓《跟我一起写 Makefile》

Makefile 是一种用于管理和自动化软件编译过程的文本文件。它通常包含了一系列规则，这些规则描述了如何根据源代码文件生成可执行文件或者其他目标文件。Makefile 的核心概念是规则和依赖关系，规则定义了如何生成一个或多个目标文件，而依赖关系则指定了生成目标文件所需要的源文件或其他依赖文件。

[!IMPORTANT] 使用 makefile 的好处？

makefile 带来的好处就是——“自动化编译”，一旦写好，只需要一个 make 命令，整个工程完全自动编译，极大的提高了软件开发的效率。make 是一个解释 makefile 中指令的命令工具。只要我们的 makefile 写得够好，make 命令会自动智能地根据当前的文件修改的情况来确定哪些文件需要重编译，从而自动编译所需要的文件和链接目标程序。

1. makefile 规则

makefile 的规则如下：

  • 目标（target）：通常是指程序生成的一个文件的名称。它可以是一个可执行文件或者是可以是一个 object file（目标文件），也可以是一个执行文件，还可以是一个标签（label）。标签这种特性可以理解为执行一个动作，不生成任何文件，这样的目标被称为伪目标。目标可以有多个。
  • 前置依赖（prerequisites）：生成该 target 所依赖的文件/target。依赖可以为空，也可以有多个。
  • 命令（command）：该 target 要执行的命令（任意的 shell 命令）。命令可以有多个，前面用 Tab 缩进，并且每条独占一行。

这是一个文件的依赖关系，也就是说，target （一个或多个的目标文件）依赖于 prerequisites 中的文件，其生成规则定义在 command 中。说白一点就是说：

如果整个工程已经编译过了，我们又重新修改了一个文件，那么直接或间接依赖它的所有目标都会重新被编译。

3. 使用变量

makefile 中的变量分为三种：自定义变量，预定义变量和自动变量。

自定义变量：定义格式的是 变量名 = 变量值 或者 变量名 := 变量值，变量代表了一个字符串，其效果可以理解成 C 语言中的宏。示例：

延迟赋值（=）和立即赋值（:=）的区别：

  • 使用 = 进行变量赋值时，称为递归展开（recursively expanded）。这意味着变量的值在定义时不会立即计算，而是推迟到变量被引用时才求值。如果变量引用的其他变量在后面被重新定义，那么变量也会动态变化。
  • 使用 := 进行变量赋值时，称为简单展开（simply expanded）。这意味着变量的值在定义的那一刻立即计算并固定下来，不会受后续其他变量定义的影响。

预定义变量：指在 Makefile 中有提前已经定义的变量，不用进行定义。这些预定义变量的名字一般都是大写的，用户可以直接使用这些变量。

6. make 的工作步骤

GNU 的 make 工作时的执行步骤如下：

  1. 读入所有的 Makefile。
  2. 读入被 include 的其它 Makefile。
  3. 初始化文件中的变量。
  4. 推导隐含规则，并分析所有规则。
  5. 为所有的目标文件创建依赖关系链。
  6. 根据依赖关系，决定哪些目标要重新生成。
  7. 执行生成命令。

7. 声明伪目标

前面提到的 clean 就是一个伪目标。“伪目标”并不是一个文件，只是一个标签，由于“伪目标”不是文件，所以 make 无法生成它的依赖关系和决定它是否要执行。我们必须要显式地指明这个目标才能让其生效（输入 make clean）。

为了避免伪目标和实际的文件重名，我们可以通过一个特殊的标记 .PHONY 来指明一个目标是伪目标，向 make 说明，不管是否有这个文件，这个目标就是“伪目标”。

伪目标一般没有依赖的文件，但伪目标可以成为依赖。

10. 使用函数

makefile 中有很多函数并且所有的函数都是有返回值的。makefile 中函数的格式和 C/C++中函数也不同，其写法是这样的： $(函数名参数 1, 参数 2, 参数 3, ...)，主要目的是让我们能够快速方便的得到函数的返回值。

这里介绍几个使用频率比较高的函数：

  1. wildcard

    语法：$(wildcard PATTERN...)

    功能：用于动态生成文件列表，通常用于指定源文件、目标文件或其他需要处理的文件集合。

    参数：pattern 是通配符模式，可以是单个模式或多个模式（用空格分隔）。支持常见的通配符，如 *（匹配任意字符序列）、?（匹配单个字符）和 [abc]（匹配指定字符集）。

    返回： 返回匹配指定模式的所有文件或目录的列表，文件名之间用空格分隔。如果没有匹配项，则返回空字符串。

  2. subst

    语法：$(subst <from>,<to>,<text>)

    功能：把字串 <text> 中的 <from> 字符串替换成 <to> 。

    返回：被替换后的字符串

  3. patsubst

    语法：$(patsubst <pattern>,<replacement>,<text>)

    功能：查找 <text> 中的单词（单词以“空格”、“Tab”或“回车”“换行”分隔）是否符合模式 <pattern> ，如果匹配的话，则以 <replacement> 替换。patsubst全称是 “pattern substitution”（模式替换）。支持 % 作为通配符，表示任意字符串。% 是 patsubst 的关键，它表示模式中可变的部分，且在 pattern 和 replacement 中必须对应。

以下是 Makefile 中常用的函数整理，分为字符串处理函数、文件名操作函数和其它常用函数三大类。

1. 字符串处理函数

这些函数用于处理和转换字符串，适用于多种文本操作场景。

函数名 语法 功能描述
subst $(subst from,to,text) 将 text 中的 from 替换为 to
patsubst $(patsubst pattern,replacement,text) 模式替换，将匹配 pattern 的部分替换为 replacement
strip $(strip string) 去掉 string 首尾的空白，并合并内部多余空白
findstring $(findstring find,in) 在 in 中查找 find 字符串
filter $(filter pattern...,text) 过滤 text 中符合 pattern 的词
filter-out $(filter-out pattern...,text) 过滤 text 中不符合 pattern 的词
sort $(sort list) 对 list 进行排序并去重
word $(word n,text) 返回 text 中第 n 个词
wordlist $(wordlist s,e,text) 返回 text 中从第 s 到第 e 个词
words $(words text) 返回 text 中词的数量
firstword $(firstword text) 返回 text 中的第一个词

2. 文件名操作函数

这些函数用于处理文件名和路径，常用于动态生成文件列表或调整路径。

函数名 语法 功能描述
dir $(dir names...) 提取文件路径中的目录部分
notdir $(notdir names...) 提取文件路径中的文件名部分
suffix $(suffix names...) 提取文件名的后缀
basename $(basename names...) 去掉文件名的后缀
addsuffix $(addsuffix suffix,names...) 为每个 names 添加后缀 suffix
addprefix $(addprefix prefix,names...) 为每个 names 添加前缀 prefix
join $(join list1,list2) 将 list1 和 list2 中的词逐一连接

3. 其它常用函数

这些函数用于实现条件判断、循环、与系统交互等功能，增强 Makefile 的逻辑控制能力。

函数名 语法 功能描述
foreach $(foreach var,list,text) 对 list 中的每个元素执行 text（var 绑定元素）
if $(if condition,then-part[,else-part]) 条件判断，如果 condition 非空，执行 then-part
call $(call variable,param1,param2,...) 调用用户定义的函数
origin $(origin variable) 返回变量的来源
shell $(shell command) 执行 shell 命令并返回输出
error $(error text...) 产生致命错误并停止 make 执行
warning $(warning text...) 产生警告但继续执行

这里值得一提的是，foreach 函数是用来做循环的，和 shell中的for语句类似。$(foreach var,list,text) 这个函数的意思是，把参数 <list> 中的单词逐一取出放到参数 <var> 所指定的变量中，然后再执行 <text> 所包含的表达式。每一次 <text> 会返回一个字符串，循环过程中，<text> 的所返回的每个字符串会以空格分隔，最后当整个循环结束时，<text> 所返回的每个字符串所组成的整个字符串（以空格分隔）将会是foreach 函数的返回值。所以，<var> 最好是一个变量名，<list> 可以是一个表达式，而 <text> 中一般会使用 <var> 这个参数来依次枚举 <list> 中的单词。示例：
