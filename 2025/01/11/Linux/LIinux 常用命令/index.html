Linux 常用命令

Linux 提供了丰富的命令行工具，用于文件操作、进程管理、权限管理等日常任务。以下是常见 Linux 指令的总结。标星为常用，要掌握，其余了解即可。

1. 文件管理

指令 功能 常用
ls 列出当前目录内容 ⭐
cd [目录名] 切换目录 ⭐
pwd 显示当前工作目录 ⭐
mkdir [目录名] 创建目录 ⭐
rmdir [目录名] 删除空目录 ⭐
rm [文件名] 删除文件 ⭐
rm -r [目录名] 递归删除目录及其内容 ⭐
cp [源文件] [目标路径] 复制文件 ⭐
mv [源文件] [目标路径] 移动文件或重命名 ⭐
touch [文件名] 创建空文件 ⭐
find [路径] -name [文件名] 查找文件 ⭐
locate [文件名] 快速查找文件 ⭐
ln -s [源文件路径] [软链接文件名] 软链接
ln [源文件路径] [硬链接文件名] 硬链接
tree 以树状结构显示目录 ⭐

2. 文件内容查看

指令 功能 常用
cat [文件名] 查看文件内容 ⭐
tac [文件名] 倒序查看文件
less [文件名] 分页查看文件，按空格或者 f 向下翻页，按 b 像向上翻页 ⭐
more [文件名] 分页查看文件，按空格向下翻页，不能往上翻 ⭐
head -n [行数] [文件名] 查看文件前 n 行 ⭐
tail -n [行数] [文件名] 查看文件后 n 行
tail -f [文件名] 实时查看文件更新

3. 权限管理

指令 功能 常用
chmod [权限] [文件名] 修改文件权限 ⭐
chown [所有者: 组] [文件名] 修改文件或目录的所有者和所属组
chgrp [组名] [文件名] 修改文件所属组 ⭐
ls -l 查看文件权限 ⭐

[!NOTE]

权限说明

权限分为三类：

  1. 所有者（User, u）：文件或目录的所有者。
  2. 组（Group, g）：文件或目录所属的组。
  3. 其他用户（Others, o）：不属于文件所有者或组的其他所有用户。

权限值：

  1. 读取（Read, r）：允许查看文件内容或列出目录中的文件，用数字 4 表示。
  2. 写入（Write, w）：允许修改文件内容或在目录中创建、删除文件，用数字 2 表示。
  3. 执行（Execute, x）：允许运行可执行文件或将目录作为路径的一部分进行访问，用数字 1 表示。

4. 文件压缩与解压

指令 功能 常用
tar -cvf [归档名.tar] [文件] 打包文件，不压缩
tar -xvf [归档名.tar] 解包 tar 文件
tar -czvf [归档名.tar.gz] [文件] 打包并压缩为.tar.gz 文件 ⭐
tar -xzvf [归档名.tar.gz] 解压.tar.gz 文件 ⭐
zip [归档名.zip] [文件] 压缩文件 ⭐
unzip [归档名.zip] 解压.zip 文件 ⭐

5. 系统信息

指令 功能 常用
uname -a 查看系统内核及版本信息 ⭐
uptime 查看系统运行时间
who 查看当前登录用户
whoami 查看当前用户
hostname 查看主机名
df -h 查看磁盘空间使用情况
du -sh [目录名] 查看目录大小
top 实时显示系统运行状态 ⭐
htop 更美观的 top 工具 ⭐
free -h 查看内存使用情况 ⭐
date 查看系统当前时间
cal 查看日历

6. 进程管理

指令 功能 常用
ps 查看当前进程 ⭐
ps aux 查看所有进程 ⭐
kill [进程号] 终止指定进程 ⭐
killall [进程名] 终止指定名称的所有进程（一个程序可以运行多个实例）
top 实时监控进程运行状态 ⭐
htop 更直观的进程管理工具
jobs 查看后台任务
fg [任务号] 将后台任务切换到前台执行
bg [任务号] 将任务切换到后台执行

7. 网络操作

指令 功能 常用
ping [地址] 测试网路连通性 ⭐
curl [URL] 下载或请求资源 ⭐
wget [URL] 下载文件 ⭐
ifconfig 查看或配置网络接口 ⭐
ip addr 查看网络接口信息
netstat -tuln 查看当前网络连接 ⭐
ss -tuln 替代 netstat 查看网络连接
scp [文件] [用户@主机: 路径] 通过 SSH 复制文件
rsync-av [源] [目标] 同步文件或目录

8. 用户管理

指令 功能 常用
adduser [用户名] 添加用户
passwd [用户名] 修改用户密码
deluser [用户名] 删除用户
id [用户名] 查看用户的 UID 和 GID
su [用户名] 切换到其他用户 ⭐
sudo [用户名] 使用超级用户权限执行命令 ⭐

9. 磁盘与挂载

指令 功能 常用
df -h 查看磁盘空间使用情况 ⭐
du -sh [目录名] 查看目录大小
mount [设备] [挂载点] 挂在设备 ⭐
umount [挂载点或设备] 卸载设备
lsblk 查看磁盘分区信息
blkid 查看设备 UUID
fdisk -l 查看分区表

10. 常用快捷键

指令 功能
Ctrl + c 终止当前命令
Ctrl + z 将任务挂起到后台
Ctrl + d 退出终端
Ctrl + l 清屏
Ctrl + a 光标移动命命令行首，等同于 Home 键
Ctrl + e 光标移动命命令行尾，等同于 End 键
Ctrl + r 搜索历史命令
Ctrl + p 显示输入的上一个历史命令，等同于 ↑ 键
Ctrl + n 显示输入的下一个历史命令，等同于 ↓ 键
Tab 命令自动补全
!! 执行上一条命令
!n 执行历史记录中的第 n 条命令
